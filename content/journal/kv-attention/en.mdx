## Why Transformers Exist

Before transformers, neural networks for language used **recurrence** (RNNs, LSTMs).

Problem: you process word by word, sequentially.

```
Input: "The cat climbed on the roof"

RNN:
  Step 1: Process "The"
  Step 2: Process "cat" (with memory of "The")
  Step 3: Process "climbed" (with memory of "The" + "cat")
  ... sequential, slow
```

That's slow in production and **impossible to parallelize**. GPU loves processing everything at once. Sequential RNNs = angry GPU.

**Transformers came to fix this:**

Process all words **at the same time**, using attention to link each word with all others.

## The Insight: Attention Is Just Basic Math

You have a sentence:
```
sentence = ["the", "cat", "climbed", "on", "roof"]
```

Step 1: Tokenize
```php
token_ids = [521, 3412, 8821, 4521, 9234]  // Vocabulary IDs
```

Step 2: Embedding (transform numbers into dense vectors)
```php
// Each word becomes a vector of dimension 768
embeddings = [
  [0.2, -0.1, 0.5, ...], // "the"
  [0.1, 0.3, -0.2, ...], // "cat"
  [0.4, 0.1, 0.0, ...],  // "climbed"
]
```

Step 3: Positional Encoding (add "position" to vector)
```php
// Because model needs to know "the" comes first
// Add position vector to each embedding
position_encoding = [
  sin(0/10000^(2i/768)), cos(0/10000^(2i/768)), ..., // position 0
  sin(1/10000^(2i/768)), cos(1/10000^(2i/768)), ..., // position 1
  ...
]

// Now each word has "position embedded"
embedded_with_position = embeddings + position_encoding
```

## Step 4: Attention (The Heart)

Attention answers the question:
"When I process the word 'climbed', which other word should I pay attention to?"

**Answer:** To "cat" (who climbed) and "roof" (where it went).

But the model doesn't know this. It learns with numbers.

```php
// You have 3 matrices the model learned:
// Query (Q), Key (K), Value (V)
// All with dimension [seq_len, d_k] where d_k = 64

Q = query_matrix @ embeddings;  // "What am I looking for?"
K = key_matrix @ embeddings;    // "Keys to find it"
V = value_matrix @ embeddings;  // "Values to return"

// Attention score = how much one word matters to another
scores = Q @ K.T / sqrt(d_k)  // matrix multiply
// Forms matrix [seq_len, seq_len]
// scores[0][1] = "how much does 'the' matter to 'cat'"

// Softmax to turn into probability
attention_weights = softmax(scores)  // Each row sums to 1
// Now it's "proportion of attention"

// Output = weighted sum of values
output = attention_weights @ V
// Each word receives combination of all other words
```

**Concrete example:**

```
Sentence: ["the", "cat", "climbed"]

When we process "climbed":
  Query["climbed"] vs Key["the"] = 0.1 (low relevance)
  Query["climbed"] vs Key["cat"] = 0.7 (high relevance)
  Query["climbed"] vs Key["climbed"] = 0.2 (medium)
  
Softmax: [0.15, 0.65, 0.20]  (normalized to 1)

Output["climbed"] = 0.15 * Value["the"] + 0.65 * Value["cat"] + 0.20 * Value["climbed"]
                   = Vector mainly mixing "cat"
```

You see? **Attention is just matrix multiplication + softmax**.

## Step 5: Multi-Head Attention

One attention head isn't enough. You want multiple "perspectives".

```php
// Head 1: Focuses on grammatical relations
attention_head_1 = attention(Q1, K1, V1)
// "the cat" = article + noun

// Head 2: Focuses on semantic relations
attention_head_2 = attention(Q2, K2, V2)
// "cat climbed" = agent + verb

// Head 3: Focuses on position
attention_head_3 = attention(Q3, K3, V3)
// Measures distance between words

// Concatenate all
output = concat(head_1, head_2, head_3)
output = linear_layer @ output  // Mix perspectives
```

GPT uses 12 heads. BERT uses 12. Claude uses 128.

Each head learned to specialize in something different.

## Step 6: Feed-Forward Network

After attention, each word goes through a simple neural network.

```php
// Applied to each position independently
output = ReLU(linear1 @ input) @ linear2
// Layer: [768 → 3072 → 768]

// ReLU = max(0, x)
// Introduces non-linearity
// Allows model to learn complex patterns
```

## Step 7: Normalization + Residual

Mathematical weirdness that makes everything work:

```php
// Residual connection (skip a layer)
output = layer_norm(input + attention(input))
output = layer_norm(output + feed_forward(output))

// Layer norm = normalize each sample to mean 0, std 1
// Stabilizes training
// Without it, training diverges
```

## Complete Stack

```
Input: "the cat climbed on the roof"
  ↓
[1] Tokenize → [521, 3412, 8821, 4521, 9234]
  ↓
[2] Embed + Position → 5 vectors [768]
  ↓
[3] Multi-Head Attention (12 heads)
  ├─ each head: Q @ K^T / √d_k → softmax → @ V
  └─ concat + linear → [768]
  ↓
[4] Add & Norm
  ↓
[5] Feed-Forward
  ├─ linear [768→3072]
  ├─ ReLU
  └─ linear [3072→768]
  ↓
[6] Add & Norm
  ↓
[Repeat steps 3-6 for each of 12 layers]
  ↓
[7] Output: 5 vectors [768] representing each word with context
  ↓
[8] Linear layer [768 → vocab_size]
  ↓
[9] Softmax → distribution over next word
```

## I Implemented It in PHP (200 Lines)

```php
class Transformer {
  public $W_q, $W_k, $W_v;  // Attention matrices
  
  public function attention($Q, $K, $V) {
    $scores = $Q @ $K->transpose();
    $scores = $scores * (1.0 / sqrt(64));
    
    $weights = softmax($scores);
    return $weights @ $V;
  }
  
  public function forward($input) {
    $x = $this->embed($input);
    $x = $x + $this->positional_encoding($input);
    
    foreach (range(0, 11) as $layer) {
      // Multi-head attention
      $attn_out = $this->multi_head_attention($x);
      $x = layer_norm($x + $attn_out);
      
      // Feed forward
      $ff_out = $this->feed_forward($x);
      $x = layer_norm($x + $ff_out);
    }
    
    return $x;
  }
}
```

## The Real Insight: Why It Works

Transformers work because **each word can "see" all other words at the same time**.

This enables:
1. **Parallelization** - processes everything at once
2. **Global context** - each word knows everything before and after
3. **Learning relationships** - attention learns which words matter
4. **Flexibility** - same architecture works for any length

The math is simple (matrix multiply, softmax), but combinations are powerful.

## Trade-off: Complexity vs Power

Transformers aren't perfect:

```
✓ Parallelizable
✗ Attention costs O(n²) memory
  → With 2048 tokens, matrix is 2048x2048
  → Memory explosion

✓ Learns long-term relationships
✗ Always wrong about "which order numbers come"
  → Needs special position encoding

✓ Works well in practice
✗ No one really understands why
  → Interpretability is open problem
```

## Summary: From Math to Product

You have 3 essential things:

1. **Embedding**: Convert text to numbers
2. **Attention**: Discover which words matter to each other
3. **Feed-Forward**: Process each word with neural network

Repeat 12+ times, skip some tensors, and you have GPT.

It's not magic. It's beautiful math.
