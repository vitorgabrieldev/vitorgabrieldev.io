## The Problem: Silent Deploy Is Risk

Your team deploys 47 changes at 2 PM. At 2:02, Slack is panicking:

```
ops: "Dashboards broke"
backend: "Which change?"
frontend: "Was it me?"
db: "Do we have a migration?"
everybody: 🤷
```

You start blaming: "Who deployed with so many changes?" But no one knows exactly what changed. 2 hours later you find it was a missing index on the migration.

## Current Deploy: Opaque Information

All your deploys have these problems:

```
✗ "Deploy 47 commits" — says nothing
✗ "All tests pass" — doesn't mean safe
✗ Random reviewers — some let entire migrations through
✗ "It's running" — yes, but at what risk?
✗ No context of change — UI? Database? Auth?
```

## Risklog: Deploy Analyzes Itself

Risklog reads each diff from your repository and describes **in natural language** what's happening.

```yaml
# Risklog receives a GitHub webhook
Webhook:
  repository: trabalhoamigo.com.br
  commits: 47
  files_changed: 23
  additions: 3421
  deletions: 892

# Analyzes each diff
- app/Models/User.php: +auth_2fa_enabled (auth risk)
- database/migrations/..._add_totp.php: +full migration (database risk)
- resources/js/components/Auth.jsx: +20 components (UI risk)
- config/stripe.php: +payment key handling (security risk)

# Classifies by type
Categories:
  - migrations: 2 (CRITICAL)
  - auth: 3 (CRITICAL)
  - payment: 1 (CRITICAL)
  - ui: 12 (LOW)
  - infra: 2 (MEDIUM)
  - docs: 5 (INFO)

# Generates risk score
risk_score: 78 / 100
reason: "2 database migrations + auth rewrite + Stripe integration changes"
```

## How Risklog Classifies Risk

### Level 1: Automatic Pattern Detection

```php
class RiskClassifier
{
  public function analyze(Diff $diff): RiskScore
  {
    $score = 0;
    
    // Database migrations = ALWAYS critical
    if ($diff->containsFile('database/migrations')) {
      $score += 40;
      $this->flag('Migration detected: schema changes');
    }
    
    // Auth code = ALWAYS critical
    if ($diff->touches('auth', 'password', 'session', 'token')) {
      $score += 30;
      $this->flag('Auth layer touched');
    }
    
    // Payment code = ALWAYS critical
    if ($diff->touches('stripe', 'payment', 'invoice', 'billing')) {
      $score += 35;
      $this->flag('Payment integration changed');
    }
    
    // Churn (many lines deleted) = risk
    if ($diff->deletions > 500 && $diff->additions < $diff->deletions * 0.3) {
      $score += 15;
      $this->flag('High deletion rate: possible refactor');
    }
    
    // Infrastructure configuration
    if ($diff->containsFile('.env', 'docker', 'nginx.conf', 'kubernetes')) {
      $score += 25;
      $this->flag('Infrastructure config changed');
    }
    
    return new RiskScore(min($score, 100));
  }
}
```

### Level 2: Impact Analysis

```php
class ImpactAnalyzer
{
  public function getAffectedServices(Diff $diff): array
  {
    return [
      'frontend' => $diff->contains('resources/js') ? 'modified' : 'safe',
      'backend' => $diff->contains('app/') ? 'modified' : 'safe',
      'database' => $diff->contains('database/') ? 'modified' : 'safe',
      'api' => $diff->contains('routes/api.php') ? 'modified' : 'safe',
      'auth' => $diff->contains('auth/', 'password', 'token') ? 'modified' : 'safe',
    ];
  }
  
  public function getRecommendedReviewers(RiskScore $risk): array
  {
    if ($risk->score > 70) {
      return ['@backend', '@security', '@devops'];
    }
    
    if ($risk->score > 40) {
      return ['@backend', '@frontend'];
    }
    
    return ['@anyone'];
  }
}
```

## Challenge: Detecting False Positives

Risklog's big problem is **not scaring everyone every time**.

Example:
```
// This HAS the word 'password' but it's safe
const PASSWORD_RESET_EMAIL_TEMPLATE = `...`;

// Risklog marks it as "auth changed" even though it's just docs
```

Solution: **Whitelist patterns**

```php
private $safePatterns = [
  'comments' => ['TODO', 'FIXME', 'example', 'template'],
  'docs' => ['README', '.md', 'docstring'],
  'tests' => ['__tests__', '.test.js', 'spec.php'],
  'config' => ['example.env', '.env.example'],
];

public function isRealChange(DiffLine $line): bool
{
  foreach ($this->safePatterns as $pattern) {
    if (str_contains($line->content, $pattern)) {
      return false; // False positive
    }
  }
  return true; // Real change
}
```

## Implementation: 3 Webhooks

```
1. GitHub → Webhook → Risklog API
   - Sends each push
   - Risklog analyzes diffs

2. Risklog → Analysis → Slack
   - Classifies risk
   - Posts paragraph
   - Suggests reviewers

3. Post-Deploy → Risklog → Learning
   - If incident happens
   - Risklog learns the classification
   - Next time detects pattern
```

## The Trade-off: Information vs Noise

**If Risklog is too aggressive:**
→ Marks everything as risk
→ No one reads anymore
→ Back to chaos

**If Risklog is too loose:**
→ Lets dangerous changes through
→ Incident in production
→ Team doesn't trust

Balance: **2-3 weeks of tuning**

You start with aggressive score, reduce as you learn.
